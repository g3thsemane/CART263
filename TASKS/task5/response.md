Project 1 Response

1. Aydan McGrail, PROJECT 1

PROJECT 1 by Aydan McGrail is one that instantly stands out due to its unique visual presentation. Bizarre, is probably the best word to describe this project at first glance, and not in a bad way at all. The user is first presented with an interface that combines a row of forks on the bottom, coins on the top, and planes flying by. The main objective of the game is to strike the planes through the given arsenal: coins that drop from the sky, forks that jump up, and a hand that reaches down. While the gameplay isn't extremely deep, the unique visual style makes for a fun experience. The visual elements make use of real-world images that have been converted into game objects, a choice that is reminiscent of early web art and games.
Overall, I would say this project is one for the eyes. It serves as a breath of fresh air, in a time where many styles seem to be repeated and copied.

2. Matia Paki, Tree Planting Simulator

The project "Tree Planting Simulator" by Matia Paki follows a clean, minimal execution that holds content relevant to contemporary issues. The game play is relatively straightforward, the user can move around a plant trees whilst a meter tracks the trees planted, if too many trees are planted, the environment becomes unstable. This procedure is done to highlight the effect of the ever-growing technology industry on the environment. Ideally, plating trees would be a beneficial action, but with it being done through a computer, it in turn causes harm. I find the messaging to be easily digested, and not obfuscated by too complex of a program or interface. The message behind this project grows more relevant as each day passes due to the aforementioned environmental concerns at the hands of technology. When consuming media, and news, through a screen it is easy to become distant to real-world issues, so projects like this are good reminders of reality.

3. Yaxuan Pang(?), Snake Game

I liked this project quite a bit, just because the snake game is such a classic browser game and it's a reminder of simpler times. Whenever I see the snake game I am reminded of the bikes from the TRON series, for some reason. This project is straightforward, which I can appreciate, and the layout and mechanics are intuitive. Upon observing the artist statement, I gathered that a main goal of the project was to simulate the play style of Pac Man, and to that I would say that it has been achieved. The gameplay, has a classic feel to it, complimented by the sort of stop-motion movement of the snake. The HUD has a sort of "retro arcade" vibe going on which fits the program. While the project is strong as is, I do the think a sound element would elevate the experience, and would work well with the tactile feel of the moving snake.
